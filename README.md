# MU Music Player

MU Music Player is a web-based music player developed using HTML, CSS, and JavaScript. I created this project to improve my web development skills and learn how to build an interactive, user-friendly music player.

## Features

- Simple and user-friendly interface
- Music playback controls
- Play and pause functionality
- Album covers and images
- Responsive design

Note: The listed features should match the functionality implemented in the project.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Live Demo

Visit the website: https://vidushi-01.github.io/Music-Player/

## Project Structure

- `index.html` - Main webpage
- `style.css` - Website styling and layout
- `script.js` - Music player functionality
- `images/` - Album covers and other images
- `music/` - Audio files used in the project

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Use the available controls to play music.

Alternatively, visit the live demo using the link above.
